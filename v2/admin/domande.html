Importa domande da CSV

Il file deve avere una riga di intestazione con queste colonne (l'ordine non conta): categoria, tipo, testo, opzione_a … opzione_f, corretta, difficolta, spiegazione. corretta è la lettera (A, B, C…) oppure Vero/Falso. Le domande vengono importate come bozze.
